# Support

## Questions and usage help

For reproducible software defects, use the [bug report form](https://github.com/armidamini/chemi/issues/new?template=bug_report.yml). For proposed capabilities, use the [feature request form](https://github.com/armidamini/chemi/issues/new?template=feature_request.yml).

Please include:
- Python version and package revision
- A minimal reproducible example
- Values with explicit units
- Expected and observed results

## Engineering limitations

This project provides introductory calculations only. It is not a substitute for professional engineering review, validated process data, applicable codes, or a detailed equipment rating. Do not use it as the sole basis for safety-critical decisions.

Do not post credentials, private process information, customer data, or other confidential material in public issues.
