# Security policy

## Supported versions

Security reports are currently accepted for the latest version on the default branch.

## Reporting a vulnerability

Please do not publish sensitive exploit details in a public issue. Use GitHub's private vulnerability reporting feature if it is enabled for this repository. If private reporting is unavailable, contact the repository owner through the contact information on their GitHub profile.

Include the affected version, a concise impact description, and reproducible steps where safe. Do not include credentials, private process data, customer information, or other confidential material.

This project is an educational calculation library and is not certified for safety-critical or regulated engineering use.
