# Changelog

All notable project changes are documented here.

## [0.1.0] - 2026-11-21

- Initial public source-code version of introductory chemical-engineering calculations.
- Added Reynolds number, Darcy friction-factor methods, Darcy–Weisbach pressure loss, and pump power.
- Added basic temperature and pressure unit conversions.
- Added sensible heat duty, log-mean temperature difference, and idealized heat-exchanger area calculations.
- Added input validation (including rejection of temperatures below absolute zero), unit tests, package metadata, MIT license, contribution guidance, Code of Conduct, and GitHub Actions CI.
- Added a worked heat-exchanger example and project metadata links.
- Documented equations, assumptions, and engineering limitations.
